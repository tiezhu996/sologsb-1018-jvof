# 声律场 · 口语发音与韵律练习工作台

使用 Svelte 与 Skeleton 从零实现的口语练习工作台。学习者可以录入句子、划分意群并标注重音、停顿和语调，随后录音、选择回听范围、逐段比较偏差；教师反馈与错词分类会和具体尝试、意群绑定。

## 功能

- 句子录入、标点智能切分、意群增删与排序。
- 逐意群标注重音词、重音强度、停顿毫秒数和语调走向。
- 调用浏览器麦克风录音，支持多轮尝试；未授权麦克风时保留可校对的离线模拟轮次。
- 每一轮尝试独立保存回听起点、终点、准确度、节奏、偏差、自评和错词分类。
- 教师可按意群留下多轮反馈；撤回、改写保留同一条反馈 ID，旧副本同步后失效。
- 每轮可打成离线练习包，录音按 SHA-256 内容哈希分片幂等上传，意群顺序版本和错词随包排队。
- 上传进度按分片写入 IndexedDB；断网、关闭页面或刷新后，已完成分片不会重传，从断点继续。
- 学生调整意群顺序会生成新的顺序版本；旧反馈继续锚定原意群/原版本，无法找到锚点时进入待处理区。
- 练习进度、目标轮次、准确度、偏差和错词分类统计。
- 使用 IndexedDB 持久化录音和全部标注，网络中断时继续编辑，不会因刷新丢失。
- Service Worker 缓存应用壳，已打开的生产页面可离线访问。
- 响应式手机/桌面布局和键盘工作流。

## 技术栈

- Svelte 4
- Vite 5
- TypeScript
- Skeleton 2
- Tailwind CSS 3

## 本地开发

```bash
npm install
npm run dev
```

Vite 开发服务器使用本地端口 `5175`，该端口不构成宿主映射。容器生产环境仅监听 `80`。

## 生产构建

```bash
npm install
npm run build
npm run preview
```

构建结果位于 `dist/`。

## Docker

```bash
docker build -t sologsb-1018 .
docker run --rm -p 10018:80 sologsb-1018
```

最终镜像使用 nginx 在容器 `80` 端口提供构建产物。宿主端口由根编排文件维护，源码和 Dockerfile 没有硬编码宿主端口。

## 离线练习包与同步模型

- `GroupVersion` 保存单个意群内容版本，`OrderVersion` 保存一整组意群顺序；反馈同时锚定 `attemptId`、`groupId` 与当时的 `groupVersionId`。
- `PracticePackage` 将一轮练习拆成录音、意群顺序、错词/评分、manifest 四部分；每片录音上传成功后立即写本地断点。
- 录音 ID 使用 SHA-256 内容哈希。同一份录音重复提交或从多台设备恢复上传时，服务端可直接复用已存在的音频分片。
- 反馈撤回/改写不生成新的随机 ID，而是用稳定 ID + `updatedAt` + `status` 做最后写入获胜；后续拉取到的设备会删除或标记旧副本，不再显示有效反馈。
- 找不到锚点的反馈不会被强行移动，先进入 `pendingFeedback` 待处理区；教师可手工归入当前意群。

## 本地数据与麦克风

- 录音 Blob、标注、尝试、反馈、练习包队列和上传/下载断点保存在 IndexedDB。
- 只有用户点击“打成离线练习包并提交”后，录音才会进入同步队列；未提交的练习只留在本机。
- IndexedDB 不可用时会退化为 `localStorage`，但浏览器安全限制下不保存原始录音 Blob。
- 当前仓库没有学校服务端，`src/sync.ts` 内置同浏览器 relay 用于演示学生/学校设备合并；接入真实后端时保持适配器方法签名，替换为 `/api/sync/*` 即可。
- 生产页面首次加载后由 Service Worker 缓存，离线状态仍可继续标注、录音、排队和保存断点。
